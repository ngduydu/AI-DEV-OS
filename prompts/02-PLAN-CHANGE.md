# Plan Change

Dựa trên yêu cầu/spec/research hiện có, lập implementation plan.

Plan phải:

- bám đúng Acceptance Criteria;
- nêu file/khu vực sẽ thay đổi;
- ưu tiên pattern hiện có;
- chia phase có thể verify;
- nêu test cụ thể sau từng phase;
- nêu migration/rollback nếu có;
- nêu rủi ro;
- không thêm refactor ngoài scope.

Với task lớn, dùng `docs/work/_template/PLAN.md`.
