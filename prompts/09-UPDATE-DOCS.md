# Update Project Knowledge

Đọc thay đổi vừa hoàn thành và xác định knowledge nào cần được lưu lâu dài.

Phân loại:

- repository-wide invariant → `AGENTS.md`;
- product/architecture/business/coding/testing/security knowledge → `docs/ai/`;
- architectural decision → ADR;
- recurring procedure → Skill;
- non-obvious failure/gotcha → `KNOWN-PITFALLS.md`;
- chỉ thuộc task hiện tại → giữ trong `docs/work/`.

Không update tài liệu chỉ để thay đổi timestamp. Không duplicate cùng một rule ở nhiều nơi nếu không cần.
